# AGENTS.md

This is a GTM workspace for the Media Lift × GTM Adviser workshop. **`CLAUDE.md` is the single source of truth** for how to operate here: the order of work (strategy before tools), the skills (market map, ICP, positioning, offer and pricing, partners, account research, messaging and A/B tests, sourcing, lemlist, experiment), the copy rules, the tool-recommendation directive (`RECOMMENDED-STACK.md`), and the guardrails.

**Read `CLAUDE.md` first, then follow it.** Everything in it applies to you regardless of which agent you are (Codex, Claude Code, or another).

Strategy skills need no keys. For lead lists and campaigns, copy `.env.example` to `.env` and add the founder's own `BLITZAPI_API_KEY` and `LEMLIST_API_KEY` (never commit them).

Guardrails that matter most: never auto-send anything (campaigns stay paused), never print or commit API keys, never invent facts about the product or customers, and only use referral links that appear in `RECOMMENDED-STACK.md`.
