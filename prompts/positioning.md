# Positioning: against the real alternative

Goal: one sentence a buyer would agree with. Positioning is context that makes your value obvious.

## Work through these, in order

1. **Competitive alternatives.** What would the customer do if you did not exist? Usually: Excel, an intern, an agency, an internal tool, a generic SaaS, or nothing. List 2 to 3 real ones, from actual conversations if possible.
2. **Unique attributes.** What do you have that those alternatives don't? Features, data, expertise, a process, a relationship.
3. **Value.** What does each attribute make possible for the customer? In their words: time saved, risk avoided, revenue, peace of mind, status.
4. **Who cares most.** Which customers care a lot about that value? This should match `output/icp.md`. If it doesn't, one of them is wrong.
5. **Market category.** Which frame makes the value obvious? ("compliance automation for TV production" vs "AI platform")

## Output: `output/positioning.md`

```
For [who] who [pain / situation],
[product] is a [category] that [main value].
Unlike [real alternative], we [unique attribute].
```

Then add:
- 3 proof points (customer quote, pilot result, expertise), or "missing" if you don't have them yet
- 1 line: what we deliberately do NOT claim

Check: would the buyer repeat this sentence to their boss? If not, rewrite.
