# One experiment at a time

Goal: leave the workshop with one experiment you run until 26 November (end of Media Lift), and know how you'll decide.

## The card

| Field | Example |
|---|---|
| Hypothesis | Heads of production respond better to a compliance angle than to a time-saving angle |
| Audience | 40 German TV production companies delivering to public broadcasters |
| Channel | Warm intros + LinkedIn |
| Volume | 20 per variant |
| Metric (close to money) | Meetings booked, pilots agreed |
| Owner | Name |
| End date | 26 Nov |
| Decision rule | ≥ 3 meetings from B and ≤ 1 from A → switch to B |

## Rules
- One variable per experiment.
- Pick the metric closest to money you can measure in two weeks.
- Write the decision rule before you start.
- After the end date: double down, change one thing, or kill it.

## Output: `output/experiment.md`
The filled card plus the first three actions for tomorrow morning.
