# Messaging and a clean A/B test

Goal: two message variants that differ in exactly one thing, so you learn something from 25 to 50 contacts each.

## Steps

1. Read `output/icp.md`, `output/positioning.md` and `output/offer.md`. The ask in every message is the first yes from `offer.md`.
2. Pick the **one variable** to test:
   - **Opener:** trigger-based vs pain-based scenario
   - **Angle:** time saved vs risk avoided vs revenue
   - **Ask:** pilot vs 15-minute call vs resource
   - **Persona:** buyer vs user
3. Write variant A and B following `prompts/copy.md`. Everything except the chosen variable stays identical.
4. Set the success metric before sending: positive replies, meetings, or pilots, per 100 contacts. Not opens.

## Output: append to `output/campaign.md`

```
Hypothesis: [variant B] beats [variant A] on [metric] because [reason].
Audience: [segment], 25 to 50 per variant.
Variable tested: [one]
A: connection note / DM1 / email 1 / email 2
B: connection note / DM1 / email 1 / email 2
Decide on: [date]
```
